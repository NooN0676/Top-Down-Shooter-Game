# Top-Down-Shooter-Game

This was initially a school project and very basic. I will update it with new features when i have new ideas.

## Getting Started

Open the project in Visual Studio Code. The workspace uses the default Java project layout:

- `src`: source files
- `lib`: dependencies
- `bin`: compiled output (auto-generated)

Run the project using the VS Code Java extension or compile manually with `javac`.
